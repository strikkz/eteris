# Eteris — литовское радио для телефона и Android Auto

Приложение само загружает список литовских станций из открытого каталога radio-browser.info,
для каждой станции выбирает поток с самым высоким качеством, а если он не отвечает — следующий.
Название текущей песни берётся прямо из потока (ICY / ID3), если станция его передаёт.

## Как получить APK

При каждом изменении в репозитории GitHub сам собирает приложение
(вкладка **Actions**, файл `.github/workflows/build.yml`) и выкладывает готовый файл
`Eteris-1.0.N.apk` на страницу **Releases**. Новые версии ставятся поверх старых.

## Android Auto

Приложения, установленные не из Google Play, Android Auto по умолчанию не показывает. Один раз:

1. На телефоне: Настройки → Android Auto (или приложение Android Auto).
2. Пролистать вниз и 10 раз нажать на «Версия» → подтвердить режим разработчика.
3. Меню ⋮ → «Настройки для разработчиков» → включить **«Неизвестные источники» (Unknown sources)**.
4. В настройках Android Auto → «Показывать приложения в Android Auto» / «Настроить меню запуска» — отметить Eteris.

## Устройство

- `StationRepository.kt` — каталог станций, выбор качества, избранное.
- `RadioService.kt` — воспроизведение (Media3 / ExoPlayer) и меню для Android Auto.
- `RadioPlayer.kt` — кнопки «следующая/предыдущая станция», возврат в прямой эфир после паузы.
- `MainActivity.kt` — экран телефона.
